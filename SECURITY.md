# Security policy

## Supported versions

Security fixes target the latest published release. Until the first release is published, this repository has no supported public release.

## Reporting

Private vulnerability reporting is not currently enabled, and GitHub Issues are currently disabled. This repository therefore does not currently provide a private reporting channel. Maintainers must enable and document a private channel before accepting sensitive reports.

Do not disclose credentials, customer data, payment data, private files, secrets, or exploit details publicly. Do not open a public issue containing sensitive details, including if Issues are enabled later. Non-sensitive defects may use a public project channel only when one is available.

## Scope and license

Reports should concern this toolkit's own skills, agent, manifests, validator, or installation guidance. Third-party WordPress, WooCommerce, Claude Code, plugin, or dependency vulnerabilities should be reported through the affected project's supported process.
